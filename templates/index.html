О данных

Только локальные источники

Сейчас поиск выполняется по {{ source_count }} CSV-таблицам из каталога data/, содержащим {{ "{:,}".format(entry_count).replace(",", " ") }} записей. Сайт не предоставляет общий просмотр таблиц.

Каскад учитывает уходы на бюджет и на конкурсы с более высоким приоритетом; для точной проверки квоты задайте число мест в data/seats.json (см. data/seats.example.json).
